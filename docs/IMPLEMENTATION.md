# 实施记录

依据用户当前要求和附件方案正文，实现单器物闭环。附件仅作为参考材料；没有执行附件里的“每天备份”“每天只推进一步”等开发指令，也没有将其待核验字段作为史实。

实际分工：用户给出产品与史实约束；编码助手创建前后端、参数化模型、界面、测试和 Render 配置。未使用外部三维模型、未下载任何文物图片。浏览器测试照片为代码合成图，并明确署名“非文物实拍”。

主要代码：
- `src/viewer.ts`：中空鼎腹、双立耳、四柱足、分层动画、照片面和射线热点。
- `src/main.ts`：照片本地处理、交互、复核、人工确认和 PNG 卡片。
- `server/domain.ts`：语体句库、来源字段、版本失效与受限生成协议。
- `server/app.ts`：会话、操作记录、生成中继、后端确认门禁和限速。
- `render.yaml`：单 Node 服务公网部署。

记录内容包括时间、操作、参数、素材署名、生成提示词、模型名称、完整输出、人工确认版本与导出披露。记录用于演示过程追踪，不是不可篡改的审计或数字签名。

事实核验策略：本次未开展外部权威史料核验，故不把后母戊鼎相关名称、年代、出土地点作为照片身份。所有具体文物事实字段保留“未核验”，模型说明则注明项目源代码来源。
